# 本地电子书阅读器（PWA）

本地优先、离线可用的多格式电子书阅读器。**没有后端，文件不上传**：书、书签、阅读进度全部存在设备自己的存储里，可以「添加到主屏幕」当成 App 用。

主要面向 iOS，桌面浏览器也能跑。

## 功能

- **格式**：EPUB、MOBI、FB2、CBZ（漫画）。TXT / PDF / AZW3 尚未支持。
- **书签**：长按选字或整段收藏，按 CFI 精确跳回原文位置，正文上叠加高亮。
- **阅读位置与跳转分离**：从书签或目录跳过去看一眼，不会改写「读到哪里了」，底栏给一颗「回原位」直接回来；只有你自己翻页才会更新进度。
- **简体 ↔ 繁体实时切换**：整本正文原地转换，不改动书籍文件。
- **排版**：字号、行距、对齐，背景三档（羊皮纸 / 白 / 黑）。
- **沉浸式阅读**：正文铺满整屏，菜单与工具条都是浮层；点屏幕左右两侧翻页，点中间收起或展开菜单。
- **阅读时长统计**：按年 → 按月 → 按书。
- **导出与备份**：书签导出为 Markdown / JSON；整个书库（含书籍本体）可导出成一份备份文件，之后恢复。
- **离线**：装过一次之后断网也能打开。

## 怎么用

1. 用 Safari 打开网页地址。
2. 分享 → **添加到主屏幕**。
3. **之后从主屏图标进入，再在那里导入书籍。**

第 3 步是认真的：Safari 标签页里的存储会被 iOS 定期清除，而且标签页与主屏 App 是两套互相看不见的存储 —— 在标签页里导入的书，装成 App 之后一本都不会出现。应用本身也会在标签页形态下提示这一点。

## 开发与构建

需要 Node 20.19+ / 22.12+。

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 产出 dist/
npm run lint       # 最小 ESLint，只查未定义标识符与未使用变量
npm run preview    # 本地预览生产包
```

## 数据与边界

- 数据只存在本机（IndexedDB），不经过任何服务器。
- **只导入你信任的文件**：阅读器会执行 EPUB 自带的脚本，恶意文件有可能破坏你本地书库。定期用「导出全库备份」留一份。
- DRM 加密的 Kindle 文件读不了，也不做解密。
- 当前状态：功能在桌面浏览器上实测过，**iOS 真机尚未验证**。

## 本期不做

DRM 解密、云同步、社交与评论、朗读（TTS）、调用在线格式转换服务（与「文件不上传」冲突）。
